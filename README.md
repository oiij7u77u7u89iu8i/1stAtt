# Flight Booking & Routing System

Консольное приложение на Java для поиска авиабилетов, автоматического построения стыковочных маршрутов и управления бронированием.

## Функциональные возможности

* **Поиск маршрутов**: Автоматическое нахождение прямых рейсов и транзитных путей с одной пересадкой между выбранными аэропортами.
* **Валидация стыковок**: Контроль времени транзита между сегментами (время пересадки должно быть строго в диапазоне от 45 минут до 24 часов).
* **Система бронирования**: Создание брони на имя пассажира с расчётом итоговой стоимости на основе выбранного класса обслуживания и примененного тарифа скидки.
* **Детализация поездки**: Посегментный вывод маршрута с отображением локального времени вылета/прилёта и чистого времени в воздухе.

## Архитектура проекта

Компоненты системы разделены по логическим зонам ответственности:
* **Интерфейс скидок (Strategy)**: Использование полиморфного расчёта стоимости билетов с помощью интерфейса `DiscountStrategy` и его реализаций (`StandardDiscount`).
* **Компоненты перелёта**: Изолированные сущности `Airport` (учёт временных зон `ZoneId`), `Flight` (информация о конкретном рейсе) и `Segment` (связка рейса и выбранного класса мест).
* **Агрегатор путей**: Класс `Route`, инкапсулирующий список сегментов и выполняющий физическую валидацию возможности пересадок (проверка совпадения городов и временных интервалов).

## Инструкция по сборке и запуску

Для компиляции и запуска приложения через командную строку выполните следующие команды:

```cmd
# Переход в корневую директорию проекта
cd /d D:\projects\untitled

# Компиляция исходного кода
javac -d target/classes src/org/example/*.java

# Запуск приложения
java -classpath target/classes org.example.Main
```
